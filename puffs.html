CLOUD FOUNDRY / ATMOSPHERE LAB

Conditions first. Pixels at every step.

1. Choose an experiment. These are atmospheric initial conditions and forcing profiles, not finished cloud presets. Temperature, vapor and liquid water are separate fields. Saturation adjustment transfers vapor to droplets and releases latent heat; evaporation reverses that process. A coarse velocity field advects the fields and responds to thermal buoyancy, vapor buoyancy and condensate loading.

2. Edit the scaffold. Use the low-poly moisture-scaffold view, Add mass, Carve and brush depth. Triangles are a disposable preview of the editable implicit volume. The scaffold sets the initial moist-air reservoir, not a hard wall around the evolved cloud. Editing it restarts formation. The cloud can move beyond it as the simulation runs.

3. Run or step formation. Seeds are warm-started from lifted moist parcels / prescribed cooled layers so you have something to inspect immediately. They are not the end result of a full weather system. Simulation steps are two physical seconds; wall-clock speed depends on the machine. Use Reset atmosphere to reproduce the seeded start. Long runs may leave the finite open domain.

4. Separate physics from illustration. Subgrid billow expansion, erosion and inflation are intentional art controls, NOT simulated turbulence. Set all three to zero for the smoothed condensate isosurface. The low-poly condensate mesh shows the resolved field before these controls. Colors are normal/thickness/AO approximations, not a full light-scattering solution.

5. Preview without baking. Live pre-bake renders the current 3D field at pixel resolution. Link orbit matches the author's viewing direction. This is a visual approximation of the exported 2D appearance: the frozen representation has fewer hidden surfaces, so viewpoint changes may differ.

6. Bake and export. Formation pauses; all views sample one fixed volume. Frozen bake is a separate maps-only renderer. Export transparent PNG sprites for immediate engine import, or the ZIP for dynamic relighting and limited parallax. Packed map PNGs use byte-exact writing. Color sprites are prelit; the geometry maps are unlit. View atlases are NOT time-animation flipbooks. Breathing is a map warp, not retained atmospheric simulation.

Scope. Warm-liquid thermodynamics only. No droplet-size distribution, ice, snow, precipitation, lightning, validated turbulence closure, or exact global water conservation. Semi-Lagrangian interpolation loses mass; sources, entrainment and open boundaries also exchange it. Projection is approximate. Orographic and frontal experiments use prescribed lift, not resolved terrain or synoptic fronts. The grid scalar is a distance estimate, not an exact Euclidean SDF. Recipes replay from seed and step count, not binary checkpoints.

SkyPaint reference. This is a separate standalone experiment inspired by SkyPaint's authoritative scalar mass / derived mesh / cloud appearance separation. It does not modify that repository and does not import SkyPaint scene files. No SkyPaint code is embedded.
